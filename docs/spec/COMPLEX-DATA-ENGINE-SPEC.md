- **Subround 2 (SR 2):** Mei – Agustus
- **Subround 3 (SR 3):** September – Desember

```
+----------------------------------------------------------------------------------------------------+
| 1. PETANI GUREM (Luas Lahan < 0,5 Hektar)                                                          |
| Proporsi Lahan Pangan & Horti: 58,2% di Pulau Jawa | 26,4% di Luar Jawa                             |

+----------------------------------------------------------------------------------------------------+
                                                  |
+----------------------------------------------------------------------------------------------------+

                                                  |

```

## 7. SPESIFIKASI MESIN SIMULASI SOM INTERNAL (GAP 7)

Modul kalkulator SOM internal memungkinkan pengguna dashboard memasukkan 4 variabel operasional riil perusahaan guna menghitung target pasar yang realistis:

### 7.1 Variabel Masukan Pengguna (User Input Parameters)
1. $N_{\text{sales}}$: Jumlah Tenaga Agronomist / Sales Lapangan aktif.
2. $C_{\text{ha\_per\_rep}}$: Kapasitas pendampingan lahan per agronomist per tahun (Standar industri: $2.500 - 4.000\text{ Ha/agronomist}$).
3. $N_{\text{kios}}$: Jumlah Kios Rekanan aktif yang membuka akun dagang (*active accounts*).
4. $S_{\text{buffer}}$: Kapasitas modal kerja kredit tempo yang dialokasikan (Juta IDR per musim).

### 7.2 Formula Mesin Simulasi SOM
$$\text{SOM}_{\text{Capacity Ha}} = \min \left( \text{SAM}_{\text{Ha}} \times \text{PenetrationTarget}\%, \; N_{\text{sales}} \times C_{\text{ha\_per\_rep}}, \; N_{\text{kios}} \times \text{RataRataSerapKios} \right)$$
$$\text{SOM}_{\text{Revenue IDR}} = \text{SOM}_{\text{Capacity Ha}} \times \text{Nilai Belanja Input per Ha (IDR)}$$
$$\text{Kebutuhan Modal Tempo IDR} = \text{SOM}_{\text{Revenue IDR}} \times 70\% \times \left( \frac{\text{Durasi Tempo Hari}}{120\text{ Hari}} \right)$$
